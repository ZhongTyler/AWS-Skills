# 游戏流程图与资源流转图

先选读者要追的范围，如一次行动、一场战斗或整局。用同一构建的规则、实机或验收记录核对起点、阶段、结算与退出。图里的假设分支标为规则推演，图注说明构建版本与图的依据。两图涉及同一过程时，复用阶段名和关键节点名，方便读者对照。

## 游戏流程图

回答玩家先看到什么、可以做什么、怎样改变局面。以实际可进入的状态为起点，按行动与状态的真实时序自上而下画主线。把选择、条件分支和回退接在决定发生的节点，标明触发条件与去向。循环回到实际恢复操作的节点，结算后接往真实下一阶段或结束。跨场时标明一次行动、回合、战斗或整局的边界，避免把场内回退画成重开整局。

## 资源流转图

先逐种核对资源从哪来、存在哪、何时投入或消耗、如何转化或损失，以及产出接回哪个阶段。按变化实际发生的阶段布置路径。区分每轮刷新与跨段留存、随身持有与正式入账、资源本身的转移与条件造成的影响。对应来源与去向必须可追，条件决定的奖励、返还、失败损失、退出或下一轮输入都接回真实节点。先保住循环、分支和退出，再调整排版与走线。

## 画面与验收

- 关键节点用图标加短标签，条件紧贴发生的位置。资源的箭头、图标与图例用对应的同一颜色。用文字、图形或线型再区分资源和条件影响，让灰度下也能判断去向。
- 窄屏优先重排节点、阶段和走线。保留一张图内可追的主线、回路和出口，按图的上下文缩短标签。按实际嵌入宽度看桌面与手机，核对文字、箭头、图例、回线与出口是否可辨。
- 对照源材料走一遍正常路线和会改变结果的分支。流程图能沿选择追到操作恢复或退出，资源图能从来源追到消耗、结算及下阶段的持有状态，再检查同名节点在正文和两图中指的是同一件事。
