# 基于性质的测试

编写、审查和调试基于性质的测试：围绕整个输入范围验证规律，而不只列举手选样例。适用于编解码、解析器、规范化、校验、数值、排序、数据结构和智能合约不变量，以及检查测试性质、生成器和缩减反例。支持 Hypothesis、fast-check、proptest、jqwik、rapid、Echidna 和 Medusa；不替代二进制模糊测试、变异测试、静态分析、性能基准或界面端到端测试。
