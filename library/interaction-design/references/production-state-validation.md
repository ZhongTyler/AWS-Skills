# 生产状态与完整操作
状态难复现、重绘后操作中断或截图无法覆盖连续任务时，从真实生产渲染入口恢复少量相关状态，沿同一条完整任务操作。状态由原业务数据和真实输入驱动，避免维护另一套相似测试界面。记录受测版本、视口、初态、输入序列、结果和剩余范围。
流程覆盖进入、选择、真实更新、继续导航、提交或取消，以及返回恢复。重绘后继续Tab、方向键和确认，按稳定身份核对选择、滚动和焦点。加载、禁用、失败及长内容只按当前功能添加；指针、键盘、手柄分别按宿主支持验证。
布局同时核对根区域、局部滚动、子内容、主要动作和安全边距。样式声明需以实际控件消费核对。对上传／处理工具，可走文件选择、参数、执行、结果焦点、下载和错误后重试，核对源文件未改与产物身份。使用获准测试材料，不能因测试发送私人内容或启用付费能力。
这些方法与宿主QA衔接，不要求额外平台。工程链路、视觉审阅、正式采用与长期收益分别记录。
