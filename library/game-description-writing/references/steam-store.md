# Steam 商店页文字

## 短描述

用纯文本交代是什么类型、玩家做什么，以及一个能帮助玩家分辨这款游戏的特点。挑选最有代表性的选择，给读者一个对玩法的预期。背景仅保留读懂行动所需的部分。

## 关于这款游戏

开篇用一轮代表性的行动把目标、选择、结果和下一个决定接起来。后续按游戏实际具备的玩法分段，每段回答一个独立问题。截图可以配在需要识别局面、对象或路线的段落，视频可以展示动作和结果。文字与素材应对应商店页面向的版本。试玩、原型及计划中的内容需要各自写明状态。

写作和提交前分别查阅 Steamworks 的[文字描述](https://partner.steamgames.com/doc/store/page/description)和[商店页及构建审核](https://partner.steamgames.com/doc/store/review_process)。字段要求按发布时 Steamworks 的说明核对。
