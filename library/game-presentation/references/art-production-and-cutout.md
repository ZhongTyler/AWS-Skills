# 生图、入景与保留原画的分层动画

## 生图前明确接口

新角色或场景先把共用画法、人物身份、当前活动和场景要求分别写清。画法描述线条、色面和明暗；人物描述稳定识别特征；活动落实承重、双手与视线；场景说明镜头、同深度参照物、光向、站位和遮挡。已有认可项直接引用，只展开本次变化。

背景先规划可站立和承托的位置、前景遮挡、可变道具与交互留位。固定安装件需要按现场透视、厚度、接触和光照试配。背景已有物件时先安排干净底层，避免重复叠放。角色身高、含武器的整图外框、脚点和场景显示尺度分别记录。

已有形象派生时说明身份源和允许改变的属性。上下文裁图覆盖判断透视、承托和光照所需结构，实际修改区用更小的蒙版界定。生成候选按源坐标映射，在声明区域内合成，再核区域外解码像素与接缝。大范围换机位需重新确定构图。

人物自身明暗与地面投影分层交接。静态投影按实际脚点、地面透视和光向制作，随人物状态显隐；移动、姿态或光照变化后重验。Alpha值与真实背景上的边缘一起检查，不能假设内部Alpha必为255。

## 已有原画转小幅分层动画

角色需要保留现有笔触、且动作适合局部刚性或网格变化时使用。先做零动作母版、小幅动作和最容易暴露接缝的姿态，再扩展当前需要的动作。

1. 按可见像素归属拆层，保留共同坐标、裁切偏移、挂点、层级及材料属性。完整手指、头发、配饰需跟随对应部件；检查原位置是否留下残片。硬件与软连接分别分配变形职责。
2. 隐藏前景检查底层。先修切片、坐标与遮挡；实际暴露的新区域才补绘。已有可用像素优先复用，生成内容只进入所需隐藏区。
3. 同尺度同脚底重组母版，比较原尺寸、叠图、剪影和关节局部。恒等变换直接保留像素，避免重复采样。区分真实形体偏差、Alpha／颜色空间误差和完全透明RGB差异。
4. 按固定绝对时间求姿并导出共同画布，保存帧序、时长、loop/once和事件。原速看动作含义，慢放及至少3倍局部找缝，检查极值与回到母版。
5. 需要交付原画／母版／旧新同帧、实际尺寸和当前版本意见时，使用宿主已配置的动画审阅器或同帧对照入口。相同清单供人审阅和Agent校验。输入或工具变化后重新核版本。

局部缺口统计只诊断声明区域，比较两版时保持区域定义一致。分层修正、补层、动作曲线与生成质量分别归因。用户确认、完整动作美术与引擎采用分别记录。

本配方用于小幅分层动画；自动拆件、完整步态、多朝向及正式艺术采用仍按实际素材验证。未配置工具时可按本节手动审阅，不自动安装执行器或调用模型。
