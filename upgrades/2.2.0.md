# 2.2.0 upgrade and recovery / 升级与恢复
Previous module version: 2.1.0. Additive methods and portable adapters; installer/schema unchanged.
先预览模块升级，再由每个客户端分别升级已选Skill。不会顺带安装新增技能、模型、MCP或其他模块。
Preview the module update, then upgrade selected client skills separately.
python scripts/skills.py upgrade --target <workspace> --platform codex
python scripts/skills.py upgrade --target <workspace> --platform codex --apply
CodeBuddy uses --platform codebuddy. Platforms keep separate transactions. Edited files conflict rather than being overwritten. Roll back using scripts/skills.py rollback --target <workspace> --platform <platform> --transaction <id> --apply. Rollback refuses later user changes; preserve old module/catalog and backups. Published tags stay immutable.
客户端事务与备份保留，回退拒绝覆盖后续修改。用户项目、账号、资料与依赖在包外；本地验证、公开发布与实际采用分别报告。
