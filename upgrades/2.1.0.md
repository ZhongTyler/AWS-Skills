# 2.1.0 upgrade and recovery

Previous independent module version is 2.0.0. Updated existing methods and added named game-change-audit and plain-language-zh skills.

Use the current AWS installer to preview and apply this module upgrade in a separate target workspace. Existing independent checkouts keep their Git/file ownership and require an owner-reviewed upgrade at their actual location. Review edited-file conflicts before applying.

The workspace transaction records changed files and supports rollback by its returned transaction ID. Keep user projects, reports, accounts, runtime and host authority outside the package. A package rollback restores managed package files, while created projects follow their own selective-upgrade workflow.

Skills users separately upgrade selected installed client methods with `scripts/skills.py upgrade --target <host> --platform <codex|codebuddy> --apply`, and restore each client's own transaction when required. Optional tools, services and agent execution follow host capability and authorization.

See README and module.json for current entrypoints and optional peers. Public tags stay immutable.
