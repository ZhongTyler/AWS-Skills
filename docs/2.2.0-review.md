## Independent use / 独立使用
No AWS, meta or private Tools installation is required. Select optional peer skills/tools only when available; otherwise use host methods and report the exact unavailable action. No private executor, account, sample, runtime, key or media was copied. The production-state recipe is bundled as a generic reference. Workflow closure uses host authority with a local minimal fallback; it does not invent an authorization or a fixed private checker.

## Collaboration and evidence / 协作与证据
Task gap -> chosen method/reference -> available tool or direct work -> host validation/adoption -> evidence to the actual owner.
Examples: game-description-writing uses Chinese editing only when relevant; game-presentation uses interaction-design for UI behavior and game-change-audit for review; dual-layer-explainer may select configured media helpers; workflow-closure returns state and publication decisions to their actual owner.
These are documented routing relationships. Inventory and dual-client transaction checks demonstrate delivery, selection, conflict and recovery mechanics. They do not measure model automatic selection, writing quality, animation quality, official adoption or long-term benefit.
