从2.2.2的42项增加到45项。新增持续文档组织、游戏开发作品介绍、游戏流程与资源图；既有42项正文、参考、代码、许可与中文映射行保持原样。新方法按冻结源逐字投影，身份见[source review](source-review-2.3.0.json)。

中文目录生成器改为按catalog实际清单核对数量、唯一ID和来源证据，不再固定42；保留空目录、重复或不匹配ID的拒绝。安装器与事务引擎不改。旧42项文案的既有润色记录保留；新增三项经维护审阅，本次没有模型调用。
